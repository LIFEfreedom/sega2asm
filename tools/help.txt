Dyna Brothers 2 — проект дизассемблирования
(в этом же дереве разбирается вторая ROM, Maui Mallard: цели те же,
 но с NAME=mauimallard ROM=platformer.gen CONFIG=platformer.yaml;
 документы — docs/mauimallard/)

Цели:
  tools     — собрать sega2asm.exe (нужен Go 1.21+)
  analyze   — пересобрать game.yaml и символы из ROM (при смене game.gen)
  split     — разрезать game.gen по game.yaml в out/
  check     — проверить покрытие ROM и побайтовое совпадение .bin
  build     — собрать build/dynabrothers2.bin (нужен ассемблер, см. ниже)
  verify    — сверить SHA-1 собранного ROM с оригиналом
  rebuild   — split + build + verify
  clean     — удалить build/
  distclean — удалить build/ и out/

Разбор (пишут в docs/ и out/, ассемблер не нужен):
  codemap   — что в каком банке лежит
  findcode  — bin-сегменты, которые на самом деле код
  codegaps  — то же, но по обходу: где именно внутри bin лежит код
  dumptext  — текст по таблицам; findtext — сырой скан
  packedtext— текст внутри сжатых блоков
  missions  — описания миссий; stages — сценарии этапов
  aiscripts — что делает противник на каждом этапе
  packmap   — сжатые блоки внутри банков кода
  terrain   — скорость и урон от местности по видам (TRARGS=--json — для ремейка)
  maps      — карты этапов в out/maps/*.png
  maptex    — карты миссий тайлами и спрайтами (MTARGS="1 5", --types, --export, --remake)
              MTARGS="--anim 1 1" — GIF с живой водой и огнём; хвостом x y ш в — окно
  menus     — восемь меню команд: картинки, пункты, доступность
              MNARGS=--hud — подложка панели, --portraits — портреты
  cutscene  — сценки между миссиями: скрипты и реплики (CSARGS=3, --back)
              CSARGS="--play 0" — проиграть сценку в GIF
              CSARGS=--story — 152 сюжетных экрана того же движка
              CSARGS=--captions — 2820 титров картинками
              CSARGS=--scenes — все 20 площадок движка и скрипты в ROM
  gfx       — графика в out/gfx/*.png
  unitgfx   — как выглядит каждый тип юнита (UARGS=номер типа)
  unitanim  — анимации юнитов по отдельности (UAARGS="5 --split")
  exportanim— анимации в раскладке ремейка (EAARGS=--all или --props)
  exportmissions — 123 миссии оригинала в формате ремейка
  animdict  — словарь анимаций: кто ставит каждый номер и что он показывает
  tileprobe — показать кусок ROM как тайлы 4bpp:  make tileprobe ADDR=020000
  pcm       — сэмплы DAC в WAV
  music     — партитуры песен; sfx — звуковые эффекты
  render    — звук с эмулятора в WAV (нужны `make deps` и компилятор C)
  z80dis    — дизассемблер звукового драйвера
  z80seq    — скрипты дорожек (Maui Mallard):  make z80seq SOUND=0
  z80render — мелодии Maui Mallard в WAV (нужен компилятор C и make deps)
  z80voice  — записи тембров (Maui Mallard):  make z80voice VOICE=0
  levels    — уровни Maui Mallard: сводка, карты, фон, метатайлы в PNG
              make levels LEVEL="--map 0"
              LEVEL="--solid 0" — профиль земли и преграды поверх карты
              LEVEL=--names — названия уровней, LEVEL="--title 0" — заставка
              LEVEL=--passwords — пароли уровней и чит на меню DEBUG
  coverage  — что в картридже разобрано, а что нет:  make coverage
              COVARGS=--raw — сырые тайлы вне системы кадров
  anim      — скрипт анимации объекта:  make anim ANIM=1D8980
              ANIM=--forms — три формы игрока и их таблицы
  unlz      — распаковать блок LZSS:  make unlz UNLZ=221904
  sprites   — кадры спрайтов в PNG (Maui Mallard):
              make sprites SPRITE="--sheet 900 64 --pal 1F6F58"
  frames    — кадры спрайтов (Maui Mallard):  make frames FRAME=0
              FRAME=--parts сборные объекты, --sets наборы графики,
              --descs описатели спрайта
  unpack    — распаковщик блока:  make unpack ADDR=060424
  vectors   — таблица исключений 68000 с нашими именами
  xcheck    — сверка дизассемблера с чужим декодером
  chains    — списки правил по приоритету (виды и ИИ противника)
  whocalls  — кто ведёт на адрес:  make whocalls WHO=008392

По умолчанию (make) выполняется split + check — это работает без ассемблера.

Ассемблер для build задаётся переменной ASM68K:
  make build ASM68K=/path/to/asm68k.exe
  make build ASM68K=/path/to/clownassembler_asm68k
