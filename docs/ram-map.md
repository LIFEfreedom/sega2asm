# Карта ОЗУ

Построено `tools/rammap.py` по дизассемблированному коду. ОЗУ Mega Drive — `$FF0000-$FFFFFF`.

Всего адресов: **296**, обращений: **2717**, баз структур (через `lea`): **96**.

## Структуры: база и раскладка полей

Найдены по `lea ($FFxxxx).l,aN` с последующими `(смещение,aN)`. Максимальное смещение даёт нижнюю оценку размера структуры.
