# ﾋﾟｰﾁｬﾝ — вид 6, талисман

Шестой и последний разбор одного вида целиком, по образцу
[game-species-trikera.md](game-species-trikera.md),
[game-species-allo.md](game-species-allo.md),
[game-species-tyranno.md](game-species-tyranno.md),
[game-species-ptera.md](game-species-ptera.md) и
[game-species-stego.md](game-species-stego.md).

Имя `ﾋﾟｰﾁｬﾝ` (ピーちゃん) — шестая строка в группе динозавров `$0497A4`, и
единственное из шести, которое не сокращение от рода: так в Японии зовут
домашнюю птичку. В `UnitTypeTable` `$01FAEE` это **тип 10** у игрока 1 и
**20** у игрока 2, дескриптор `$154`, блок параметров **`$022AEA`**.

Игра выделяет его особо в двух местах сразу: перепись `$01D746` считает
вид 6 **отдельным полем** `+$8`, мимо травоядных и хищников, а меню
маркировки предлагает его **отдельной строкой**, наравне с ﾃｨﾗﾉ и двумя
целыми группами ([game-species.md](game-species.md)).

## Как проверены числа

```
xxd -s $((0x022AEA)) -l 224 -g 2 game.gen
```

## Находка попутно: `+$C4`…`+$CA` — это удар улучшенного юнита

В четырёх прошлых разборах эти четыре слова числились неопознанными. Они
читаются в `$01B528`, прямо перед умножением на защиту цели:

```asm
	add.w	d5,d5             ; d5 = степень исхода
	btst	#5,$11(a2)        ; Elite?
	beq.w	loc_01B53E
	addi.w	#$00C4,d5         ; улучшенный — ладдер +$C4
	move.w	($0,a4,d5.w),d7
	bra.w	loc_01B546
loc_01B53E:
	addi.w	#$000A,d5         ; обычный — ладдер +$0A
	move.w	($0,a4,d5.w),d7
```

То есть `+$C4`…`+$CA` — та же четвёрка степеней, что `+$0A`…`+$10`, но
для юнита с купленным улучшением:

| вид | обычные 0/1/2/редкая | улучшенные 0/1/2/редкая |
|---|---|---|
| 1 ｽﾃｺﾞ | 75 / 100 / 125 / 1300 | 100 / 125 / 150 / 1200 |
| 2 ﾄﾘｹﾗ | 150 / 250 / 350 / 1800 | 200 / 300 / 500 / 1200 |
| 3 ｱﾛ | 500 / 650 / 800 / 2000 | 700 / 800 / 1000 / 1800 |
| 4 ﾃｨﾗﾉ | 750 / 850 / 1100 / 2500 | 1000 / 1300 / 1500 / 2000 |
| 5 ﾌﾟﾃﾗ | 300 / 400 / 650 / 1800 | 400 / 500 / 900 / 1500 |
| **6 ﾋﾟｰﾁｬﾝ** | 50 / 75 / 100 / 2500 | **50 / 75 / 100** / 1500 |

Числа сходятся с ожидаемым уроном из [game-damage.md](game-damage.md)
до единицы, и заодно объясняют, почему улучшение **снижает** силу редкой
степени: это не отдельная механика, а просто вторая таблица.

И сразу видно исключение: **у ﾋﾟｰﾁｬﾝ улучшение не поднимает обычные
степени вовсе**. Он единственный, у кого вся прибавка — в шансе редкого
удара.

## Характеристики

| поле | значение | что означает |
|---|---|---|
| `+$04` | 1300 | максимум здоровья |
| `+$06` / `+$08` | 500 / 300 | пороги «ранен» и «тяжело ранен» |
| `+$0A`…`+$10` | **50 / 75 / 100** / **2500** | слабейший обычный удар и сильнейшая редкая степень, вровень с ﾃｨﾗﾉ |
| `+$C4`…`+$CA` | 50 / 75 / 100 / 1500 | то же после улучшения |
| `+$AE` / `+$AF` | **255** / 200 | защита из 256 — **худшая в игре**: проходит почти весь урон |
| `+$A9` | **128** | шанс случайного поворота — **50%**, наибольший из шести |
| `+$AA` | 52 | шанс пойти по подсказке приказа — 20,3% |
| `+$AB` | 15 | такт дозревания яйца, 5,9 секунды — второе место |
| `+$AC` / `+$AD` | 1 / 50 | шанс редкой степени: 0,4% и 19,5% после улучшения |
| `+$B4` | 800 | награда владельцу за убийство, вровень с ﾄﾘｹﾗ |
| `+$BC` / `+$BD` | 5 / 10 | в очередь списания при потере и при убийстве |
| `+$BE` | 10 | опыт убийце за его голову |
| `+$C0` | 999 | мёртвое поле: правила взросления нет |
| `+$C2` / `+$C3` | 8 / **4** | зрение: **улучшение уменьшает его вдвое** |
| `+$CC` | **800** | питательность своей туши — наибольшая из шести |
| `+$CE` / `+$D2` | 2400 / 2200 | порог размножения; **улучшение его снижает** |
| `+$D6` | 1000 | цена родов здоровьем |

## Чем он выделяется среди шести

| ось | ﾋﾟｰﾁｬﾝ | место среди шести |
|---|---|---|
| защита | 255 | **худшая**: получает 99,6% чужого урона |
| обычный удар | 50 | **слабейший** |
| редкая степень | 2500 | **вровень с сильнейшим** |
| случайные ходы | 50% | **наибольшие** |
| зрение после улучшения | 8 → 4 | **единственный случай, когда улучшение отнимает** |
| порог размножения после улучшения | 2400 → 2200 | **единственный случай, когда улучшение его снижает** |
| его туша | 400 чужому, 800 своему | **самая питательная из шести** |
| еда | **ни трава, ни падаль** | единственный |
| место в переписи | отдельное поле | единственный |

Портрет: **зверёк, которого нельзя ни прокормить обычным способом, ни
поставить в строй, но которого игра считает отдельно и позволяет назначить
целью**. Он не боец и не кормилец, он — фигура на доске.

## Бой: лотерея

Ожидаемый урон за удар — 78, после улучшения 348. Прирост ×4,4, самый
большой в игре, — и весь он оттого, что редкая степень 1/256 превращается
в 19,5%.

Сорок ударов, чтобы убить тираннозавра обычным порядком, — и один шанс
из 256 убить его сразу: редкая степень бьёт на 2500, ровно в его полный

этот билет **портит**: шанс вырастает в пятьдесят раз, но выигрыш падает
с 2500 до 1500, то есть одним ударом уже никого не убить.

## Еда: только яйца

В его скрипте нет ни `RuleGraze`, ни `RuleEatCarcass`, ни
`RuleApproachCarcass`. Маска ручного выпаса в `RulePlayerControl`
`$01798E` равна `$00100486` — виды 1, 2, 7, 10 и 20, — шестого там нет;
маска ручного поиска падали `$0010DF38` — виды 3, 4, 5, 8…12, 14, 15,
20 — тоже без шестого.

Остаётся вторая строка скрипта, `RuleDevourNeighbour` `$01977C`: сосед,
чьё действие входит в набор `ActionSetMoving` `$01682C` (`$01`…`$09`),
записывается в `+$20`, и `BeginDevourNeighbour` ставит едоку действие
`$20`. Кормит же `ActionDevour` `$01A688` только тогда, когда у жертвы
взведён бит 7 байта `+$C`, а его ставят ровно в трёх местах, и все три —
про дозревающее яйцо ([game-actions.md](game-actions.md)).

**То есть единственная еда талисмана — чужие яйца.** Ровно этому и учит
четвёртый урок (`$198582`):

> ﾀﾏｺﾞｦ ﾀﾍﾞｻｾﾖｳ! **ﾋﾟｰﾁｬﾝﾊ ｱﾚﾁﾊ ｱﾙｶﾅｲﾉﾃﾞ** ｱﾒｦ ﾌﾗｾﾃ ﾄｵﾘﾐﾁｦ ﾂｸｯﾃ
> ｱｹﾞﾖｳ. ﾀﾏｺﾞｶﾗｶｴｯﾀ ﾃｷﾊ ﾃｨﾗﾉﾃﾞ ｾﾞﾝﾒﾂﾀﾞ.

«Дай ему съесть яйца! ﾋﾟｰﾁｬﾝ не ходит по пустоши, так что пусти дождь и
проложи ему дорогу. А кто из яиц всё-таки вылупился — тех начисто
тираннозавром».

Обе половины проверяются. Про яйца — выше. Про пустошь — в наборах
местности: при четырёх приказах из пяти его набор A равен `$0020FCFF`,
то есть типы 0–7 и 10–15, **без 16, 17, 18 и 19**. Пустошь (тип 17, см.
[game-species-ptera.md](game-species-ptera.md)) в набор не входит, и
машинка шага туда не пустит.

## Местность

| местность | шаг `A` | урон при ходьбе `B` | урон при входе `C` |
|---|---|---|---|
| открытая земля и трава (0…7, 10, 21) | 23 | 3 | 5 |
| сырая земля (8, 9) | 27 | 10 | 50 |
| лава, огонь, разлом (11, 12, 13) | 99 | **9999** | **9999** |
| лёд (14) | 10 | 10 | 10 |
| 15…17 | 30 | 10…100 | 10…100 |
| 18, 19 — вода | 40 | 100 | 200…400 |

Ходит он дёшево: 23 за шаг и 3 урона — вровень с ﾌﾟﾃﾗ и ﾃｨﾗﾉ, вдвадцатеро
дешевле ｽﾃｺﾞ. Странность из [game-terrain.md](game-terrain.md) как раз про
него: **улучшенный ﾋﾟｰﾁｬﾝ проходит разлом (тип 13) за 18**, тогда как
таблицы B и C на этом типе у него остались 9999. Зайти может, зайдя —
гибнет.

## Поведение: скрипт `AiSpecies06` `$017298`

```
 1. встретить лицом, фильтр FilterFaceTargetA              [конец]
 2. сосед в действии $01…$09 → повернуться к нему и съесть  [конец]
 3. развернуться на 180                                    [конец]
 4. обновить занятость своей клетки                        [конец]
 5. если это выбранный юнит игрока → управление            [конец]
 6. если ранен — паника: 12,5%, при тяжёлой ране 25%       [конец]  ← ВЫСОКО
 7. с вероятностью 128/256 (50%) поворот на ±1             (без выхода)
 8. если действие $2D — продолжать идти                    [конец]
 9. ─── если РАНЕН: ────────────────────────────────────────
      9a. ближний поиск идущего врага → шагнуть            [конец]
      9b. тяжело ранен → дальний поиск идущего юнита       [конец]
          иначе → правило «только если я вид 1» (мёртвое, см. ниже),
                  затем дальний поиск идущего юнита        [конец]
10. если приказ ﾗﾝﾄｳ и есть враг → в драку                  [конец]
11. если рядом юнит вне маски видов → подойти               [конец]
12. ближний поиск идущего врага                             [конец]
13. если HP ≥ 2400 → родить                                 [конец]
14. если приказ ﾄﾂｹﾞｷ → взять назначенную цель,
    иначе вступить в стычку с соседом                       [конец]
15. если приказ НЕ ﾊﾝｼｮｸ → дальний поиск идущего врага      [конец]
16. сойти с чужой местности                                 [конец]
17. случайный ход                                           [конец]
18. 1/256 — встать столбом (действие $00)                   [конец]
19. побродить с таймером
```

Три черты сразу бросаются в глаза.

**Паника стоит шестой строкой** — выше, чем у кого бы то ни было. Раненый
ﾋﾟｰﾁｬﾝ бросает всё раньше, чем успеет что-то решить.

**Он гоняется за движущимися.** Четыре строки из девятнадцати — это
`RuleChaseMovingEnemy`, `RuleChaseMovingFar`, `RuleChaseMovingEnemyFar`:
цель выбирается не по виду и не по ранам, а по тому, что она **идёт**.
Вместе с правилом «съесть соседа в движении» получается зверёк, который
бегает за всем, что шевелится.

**Строка 18, `RuleRareStop` `$017C48`** — один шанс из 256 просто
остановиться. Больше ни у кого этого нет.

### Мёртвая строка в скрипте

Строка 9b в некритической ветке зовёт `RuleChaseMovingAsSpecies1`
`$0185A6`, а тот берёт фильтр `FilterMovingIfSpecies1` `$0190D8`:

```asm
	move.b	$C(a2),d2         ; a2 — САМ ищущий, не кандидат
	andi.w	#$001F,d2
	cmpi.b	#$01,d2
	bne.w	<отказ>           ; не вид 1 — правило молчит
```

Проверяется вид **самого** юнита, и он должен быть первым. Во всём ROM
`RuleChaseMovingAsSpecies1` вызывается ровно один раз — из скрипта вида 6.
Значит **сработать это правило не может никогда**: его поставили туда,
где условие заведомо ложно. Похоже на копию строки из скрипта ｽﾃｺﾞ,
оставшуюся после правки.

### Ручное управление у него своё

`RulePlayerControl` `$01798E` разбирает выбранный юнит по виду, и вид 6 —
первая же развилка (`$017A36`):

| вид | что даёт ручное управление |
|---|---|
| **6** | `RuleChaseMoving` — погоня за движущимся |
| 3, 4, 5, 8…12, 14, 15, 20 | `RuleApproachCarcass` — идти к падали |
| 1, 2, 7, 10, 20 | `RuleGraze` — пастись |

То есть под рукой игрока травоядное ест, хищник идёт к мясу, а талисман
гонится. Своей еды у него нет и здесь.

## Экономика

| статья | значение |
|---|---|
| доход с юнита за тик, стадо ≤6 / ≤12 / ≤20 / больше | 10 / 5 / 2 / 1 |
| награда за убийство врага, `+$B4` по виду убийцы | **800** |
| яйцо, `CostsEggs` `$022374` | **1030** |
| переделка яйца в ﾋﾟｰﾁｬﾝ, `CostsRemodel` `$02238C` | **927** |
| улучшение, `$0223A4` | 1854 |
| в очередь списания при потере и при убийстве им | 5 / 10 |

Странная пара чисел. Доход у него хищный (10 и ниже), а награда за
убийство травоядная (800, как у ﾄﾘｹﾗ) — при том, что убивает он хуже всех
в игре. И он один из двух видов, кого **дешевле переделать, чем отложить**:
927 против 1030 (второй — ﾄﾘｹﾗ).

Дороже него стоит только ﾃｨﾗﾉ, а туша у него самая питательная из шести —
400 чужому едоку и 800 своему. Тысячу очков здоровья вложить, чтобы
получить зверька, которого выгоднее всего съесть.
