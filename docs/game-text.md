# Весь текст игры

Собрано `tools/dumptext.py` по таблицам, а не сканированием: каждая
строка ниже стоит там, где её читает код. Сырая выгрузка всех прогонов
байт — в [text.md](text.md), но половина её улова это графика.

Кодировка — JIS X 0201, полуширинная катакана, байт на символ,
терминатор `$00`; `$40` переключает размер шрифта и в текст не идёт.

## Где это показывают

Весь сюжетный текст игры — это **напутствие перед миссией**. Другого
повествования в ROM нет: ни заставок между этапами, ни реплик по ходу
боя. Экран рисует `ScreenAfterBattle` `$052BCE`, который получает два
байта состояния: `+$0` выбирает вид экрана, `+$1` — номер миссии.

```asm
; $006FE4
	movea.l	(MainStatePtr).l,a6
	move.b	$0(a6),d0         ; режим: 0 обучение, иначе кампания
	move.b	$1(a6),d1         ; номер миссии
	move.w	d0,-(a7)
	move.w	d1,-(a7)
	jsr	(ScreenAfterBattle).l
```

Дальше `GfxState_056310` `$056310` вычитает из номера единицу, берёт
корень `$197160` (кампания) или `$1971BA` (обучение) и выводит пять
строк блока с шагом `$0100` по таблице имён.

Номер напутствия — **не** номер карты. Описание миссии лежит сжатым:
`LoadMissionState` `$006C06` берёт главу из `$060400` и распаковывает
её по `$5C` байт на миссию. Распаковщик разобран (см.
[game-compression.md](game-compression.md)), поэтому в таблице ниже
стоят оба числа: `+$1` — номер напутствия, `+$3` — номер записи в
таблице этапов `$164400`. Они расходятся почти везде.
