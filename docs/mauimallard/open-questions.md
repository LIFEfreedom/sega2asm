# Что осталось неразобранным

Один список на весь проект. Заводить вопросы сюда, а не в тематические
файлы: у соседнего разбора они разошлись по двадцати пяти файлам и
протухли.

## Разметка и инструменты

1. **Что лежит в оставшихся 12% окон кода.** 15 КБ внутри `$28D000-$2AC000`
   обход кодом не считает. Часть — таблицы переходов и образ драйвера Z80,
   часть — процедуры, до которых добираются по вычисленному адресу.
2. `codemap.py` считает по колонкам, которые описывают ОЗУ Dyna Brothers 2;
   для этой игры их надо либо переопределить, либо не смотреть на них.
3. `findtext.py`, `dumptext.py`, `packedtext.py` рассчитаны на таблицы
   строк Dyna Brothers; здесь текст лежит иначе (обычный ASCII), нужен свой
   съёмник.

## Данные

4. **Кто читает таблицу `$001000`** — 8 412 длинных указателей в самом
   начале картриджа ведут в низкие банки, но кто берёт саму таблицу, не
   найдено. То же про `$1FBC5C` (141 указатель в код) и `$1FF5F0` (136).
5. **Формат описателя кадра спрайта.** По `$1BCC4C` и дальше с шагом `$12`
   лежат записи вида `00 00 00 00 F6 04 F2 06` — нули и маленькие знаковые
   смещения. Раскладка не разобрана.
6. **Раскладка записи объекта.** Известны `+$2` (следующий в списке),
   `+$10` (ключ сортировки), `+$1E` (обработчик), `+$28` (счётчик кадров),
   `+$36` (номер тайла для передачи). Видны, но не опознаны `+$12`, `+$18`
   (скорость по вертикали), `+$30` (флаги: биты 0, 2, 8, 9, 11, 14), `+$4C`.
   Размер записи, их общее число и где лежит пул — неизвестны.
7. **Что упорядочивает ключ `+$10`** — отрисовку, обновление или что-то ещё.
8. **Что такое `$1FD7AC`** — адрес кладут в `$FFFFFD74` при старте и ещё раз
   в `$2984AC`. Рядом лежит текст меню.
9. **Пароли.** В меню есть `PASSWORD`, но где таблица паролей — не искали.
10. **Отладочное меню.** Текст меню записан дважды: с пунктом `DEBUG` и без.
    Чем выбирается вариант — неизвестно.
11. **Кто зовёт отладочную проверку очереди DMA** `$299604` — ту, что
    выполняет `ILLEGAL` при несовпадении. Ссылок на неё не найдено.

## Звук

12. **Что внутри записи тембра** — 39 байт, разобран только первый (тип:
    FM, ударные, PSG). Остальное — параметры операторов и огибающие.
13. **Таблица 2** (32 байта на запись) опознана по месту чтения, не по смыслу.
13а. **Чем отличаются типы тембра 2 и 3** — оба PSG, но разные наборы каналов.
14. **Что делают биты 6 и 7 состояния слота** (команды `$66`/`$67`,
    они же команды `$07`/`$0E` от 68000).
15. **Самоправка `$02CF`** в насосе DAC: при делителе 10 и больше туда
    кладут `$00` вместо `$C9`. Зачем — не объяснено.
16. **Зачем драйверу шестнадцать команд, которых игра не зовёт.** Возможный
    ответ — драйвер общий для нескольких игр издателя.

## Игра

17. Главный цикл `$29806C` прочитан бегло: видно вызовы по флагам
    `$FF213C`, `$FFFFFD82`, `$FF1A6C`, `$FF1394`, но что каждый из них
    означает — не установлено.
18. Смена костюма (главная механика игры) в коде не найдена.
19. Как устроен уровень: `$1FCC08` даёт процедуру на уровень, `$1FCBAC` —
    список объектов, но формат записи списка разобран только до слова-
    признака конца (отрицательное) и полей `+$4C`, `+$12`.

## Закрыто

| было | чем кончилось |
|---|---|
| «`--drop-bin` снимает целый прогон, это стоило 10 КБ кода» | снимает одну команду; 12 расхождений стоят 46 байт, разобранного кода стало 115 680 |
| «сжата ли графика» | не сжата: тайлы 4bpp уходят в VRAM прямо из ROM, распаковщика нет ([graphics.md](graphics.md)) |
| «`$208000-$288000` похоже на сжатое» | карты имён VDP; высокая энтропия от неповторяющихся номеров тайлов |
| «низкие банки — не готовые тайлы» | готовые; ошибся сам разбор: лист рисовался по таблице указателей `$001000` |
| «кто ставит задания в очередь DMA» | `$296056`, `$296078`, `$296098`, `$2960DE`; разгребает копия в ОЗУ по `$FFFFFC12` |
| «драйвер Z80 не разбирался вовсе» | разобран: почтовый ящик, 21 команда, четыре таблицы, DAC ([z80.md](z80.md)) |
| «что в четырёх таблицах» | тембры (39 байт), записи по 32 байта, 169 звуков, каталог 48 сэмплов |
| «смысл команд `$10`, `$12`, `$16`, `$1B`» | начать звук, остановить звук, остановить всё, записать параметр `$1B22+n` |
| «где кончаются таблицы и начинаются сэмплы» | сэмплы `$2C7A9B`..`$2F8BF2`, границы взяты из каталога, а не на глаз |
| «формат скрипта дорожки» | разобран: ноты, 19 команд, два вида чисел; все 363 дорожки разбираются до конца (`make z80seq`) |
