# Что осталось неразобранным

Один список на весь проект. Заводить вопросы сюда, а не в тематические
файлы: у соседнего разбора они разошлись по двадцати пяти файлам и
протухли.

## Разметка и инструменты

1. **Что лежит в оставшихся 12% окон кода.** 15 КБ внутри `$28D000-$2AC000`
   обход кодом не считает. Часть — таблицы переходов и образ драйвера Z80,
   часть — процедуры, до которых добираются по вычисленному адресу.
2. `codemap.py` считает по колонкам, которые описывают ОЗУ Dyna Brothers 2;
   для этой игры их надо либо переопределить, либо не смотреть на них.
3. `findtext.py`, `dumptext.py`, `packedtext.py` рассчитаны на таблицы
   строк Dyna Brothers; здесь текст лежит иначе (обычный ASCII), нужен свой
   съёмник.

## Данные

4. **Что за четыре байта в `+4` кадра спрайта.** Их не читает ни одна
   найденная процедура. Похоже на габарит `x0, x1, y0, y1`: сходится
   статистически (83%, 80%, 93-96%), но доказательства нет.
5. **Какая палитра какому кадру положена.** Цвета грузятся блоками по 128
   байт (`$2A58B6` -> `$FFFFDC40` -> CRAM `$2A58C4`), в ROM их 32 по
   правилу `0BGR`, в коде прямо названы `$1F6F58` и `$1FB158`. Связи
   «кадр или уровень -> блок» нет, поэтому `make sprites` красит тем, что
   укажут ключом `--pal`.
6. **Кто читает `$1FBC5C`** (141 указатель в код) и `$1FF5F0` (136).
7. **Формат описателя кадра спрайта.** По `$1BCC4C` и дальше с шагом `$12`
   лежат записи вида `00 00 00 00 F6 04 F2 06` — нули и маленькие знаковые
   смещения. Раскладка не разобрана.
8. **Раскладка записи объекта.** Известны `+$2` (следующий в списке),
   `+$8` (словный указатель: у части — на родителя, у родителя — на слот
   сборного объекта), `+$C` (кадр), `+$10` (ключ сортировки), `+$12`/`+$14`
   (положение x, y), `+$1E` (обработчик), `+$22` (скрипт анимации),
   `+$28` (счётчик кадров), `+$34`/`+$36` (место в VRAM и номер тайла),
   `+$3C` (номер части), `+$3E` (словный указатель на следующую часть).
   Не опознаны `+$18` (скорость по вертикали), `+$30` (флаги: биты 0, 2, 8,
   9, 11, 14), `+$4C`. Размер записи и где лежит пул — неизвестны.
   Флаги в `(a0)`: бит 8 — объект сборный, биты 11 и 12 — отражения,
   бит 13 — не рисовать, бит 14 — не отсекать по экрану.
9. **Что упорядочивает ключ `+$10`** — отрисовку, обновление или что-то ещё.
10. **Что такое `$1FD7AC`** — адрес кладут в `$FFFFFD74` при старте и ещё раз
   в `$2984AC`. Рядом лежит текст меню.
11. **Пароли.** В меню есть `PASSWORD`, но где таблица паролей — не искали.
12. **Отладочное меню.** Текст меню записан дважды: с пунктом `DEBUG` и без.
    Чем выбирается вариант — неизвестно.
13. **Кто зовёт отладочную проверку очереди DMA** `$299604` — ту, что
    выполняет `ILLEGAL` при несовпадении. Ссылок на неё не найдено.

## Игра

14. Главный цикл `$29806C` прочитан бегло: видно вызовы по флагам
    `$FF213C`, `$FFFFFD82`, `$FF1A6C`, `$FF1394`, но что каждый из них
    означает — не установлено.
15. Смена костюма (главная механика игры) в коде не найдена.
16. Как устроен уровень: `$1FCC08` даёт процедуру на уровень, `$1FCBAC` —
    список объектов, но формат записи списка разобран только до слова-
    признака конца (отрицательное) и полей `+$4C`, `+$12`.

## Закрыто

| было | чем кончилось |
|---|---|
| «`--drop-bin` снимает целый прогон, это стоило 10 КБ кода» | снимает одну команду; 12 расхождений стоят 46 байт, разобранного кода стало 115 680 |
| «сжата ли графика» | не сжата: тайлы 4bpp уходят в VRAM прямо из ROM, распаковщика нет ([graphics.md](graphics.md)) |
| «`$208000-$288000` похоже на сжатое» | карты имён VDP; высокая энтропия от неповторяющихся номеров тайлов |
| «низкие банки — не готовые тайлы» | готовые; ошибся сам разбор: лист рисовался по таблице указателей `$001000` |
| «кто ставит задания в очередь DMA» | `$296056`, `$296078`, `$296098`, `$2960DE`; разгребает копия в ОЗУ по `$FFFFFC12` |
| «драйвер Z80 не разбирался вовсе» | разобран: почтовый ящик, 24 команды, четыре таблицы, DAC ([z80.md](z80.md)) |
| «что в четырёх таблицах» | тембры (39 байт), записи по 32 байта, 169 звуков, каталог 48 сэмплов |
| «смысл команд `$10`, `$12`, `$16`, `$1B`» | начать звук, остановить звук, остановить всё, записать параметр `$1B22+n` |
| «где кончаются таблицы и начинаются сэмплы» | сэмплы `$2C7A9B`..`$2F8BF2`, границы взяты из каталога, а не на глаз |
| «формат скрипта дорожки» | разобран: ноты, 19 команд, два вида чисел; все 363 дорожки разбираются до конца (`make z80seq`) |
| «что внутри записи тембра» | для FM разобрана целиком: 4 оператора, алгоритм, LFO, особый режим канала 3 (`make z80voice`) |
| «39 байт у типов 2 и 3» | PSG: тип 2 — тон, тип 3 — шум; читаются шесть байт, это трёхфазная огибающая плюс управление шумом |
| «чем отличаются типы 2 и 3» | набором каналов: тип 2 идёт в тональные каналы PSG, тип 3 — в канал шума |
| «39 байт у ударного тембра» | их там и нет: запись типа 1 — два байта, тип и поправка скорости сэмпла |
| «таблица 2» | 25 последовательностей модуляции высоты: начальный шаг и тройки «тики, шаг» (`make z80voice VOICE=--mod`) |
| «биты 6 и 7 состояния слота» | бит 6 — перезапускать модуляцию с каждой нотой; бит 7 пишут две команды и не читает никто |
| «самоправка `$02CF`» | разоружает насос после каждого сэмпла при делителе ≥ 10; в этой игре не срабатывает, а если заставить — звук не меняется |
| «незваные команды» | их девятнадцать, а не шестнадцать; тринадцать дублируют команды дорожки, шесть — про вмешательство снаружи |
| «кто читает таблицу `$001000`» | `$2A0306`, база `$001080`: это оглавление 2 880 кадров спрайтов, каждый — список передач в VRAM (`make frames`) |
| «списки с записи 2 880» | сборные объекты: 608 записей, 11 290 частей; плюс шесть наборов графики (`--parts`, `--sets`) |
| «восемь неразобранных записей» | пустые: счётчик 0, четыре байта, подряд номера 140-147 |
| «слово-ссылка в раскладке» | не признак группы, а **адрес набора графики**; сама «раскладка» оказалась сборным объектом |
| «кто читает раскладки» | `$296F68` → `$296E96` → `$296D88`; кадры собирает `$29612E` (тело `$296208`), а скрипт анимации крутит `$297010` |
| «где таблица спрайтов» | `$FF050C`, 80 записей, уходит в VRAM `$F400` из `$29630A` |
| «можно ли выгрузить графику» | да: `make sprites`, тайлы по столбцам, цвет 0 прозрачен; шрифт и Дональд узнаются глазами |
