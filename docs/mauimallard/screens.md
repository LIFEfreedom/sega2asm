# Экраны вне уровня и HUD: спецификация для ремейка

Всё, что игрок видит не на уровне: заставки при включении, меню и пароль,
демо, заставки миров с сюжетом, итоги мира и бонуса, гибель, продолжение,
конец игры, концовка и титры, пауза и индикаторы на экране уровня. Порядок,
длительности, чем пропускается, что на экране и какие тексты.

Числа выгружает `tools/screenspec.py` в `out/mauimallard/export/screens.json`;
рядом, в `screens.sources.json`, у каждого числа адрес и текст команды.
Все тексты экранов — там же, дословно; на консоль их выводит
`python tools/screenspec.py --text`. Картинки слоёв рисует
`make levels LEVEL=--screen`, глифы HUD — `make levels LEVEL=--hud`.

## 0. Общее

* **Переходы** — затемнение палитры за **16 кадров** (`PaletteFadeTo`,
  `$290C70`), и в темноту, и из неё.
* **Ожидание** бывает двух видов: `$2A562A` — n кадров или до нажатия
  **Start**, `$2A561A` — ровно n кадров. Ниже «пропуск: Start» значит
  первое.
* **Шрифт** `$1EC49E`: 64 глифа 16 × 16, ширина знака 12, пробела 8
  (`$1EA5FE`). Страница текста — строки по центру X = 160, шаг 16 точек;
  буквы — спрайты, живут столько, сколько страница.
* **Надписи крупными буквами** (LEVEL COMPLETE, CONTINUE, GAME OVER,
  названия миров) — отдельные спрайты-буквы, таблица «буква, x, y»; буквы
  0-25 — A-Z, 26 — слово THE. Падают сверху по одной.
* **Актёры** — спрайты сцен: список «x, y, скрипт анимации, обработчик»;
  в JSON у каждого экрана свой список.
* Экраны строятся из одних и тех же слоёв: **силуэт острова** (`$1F6548`
  или `$1F6850`) на плоскости A и **задник** без изгороди (`$1F813A`) на
  плоскости B.

## 1. Порядок экранов

```
включение: пароль = AAAAAA
  SEGA -> Disney Interactive -> presents -> титульный -> главное меню
главное меню:
  START ........ новая игра
  OPTIONS ...... настройки -> меню
  PASSWORD ..... ввод; верный -> игра с уровня пароля, неверный -> меню
  (DEBUG) ...... после IMCARY и MAUIMM
  простояло 600 кадров -> демо (одно из трёх по кругу)
    демо кончилось -> снова с SEGA;  Start в демо -> титульный -> меню
новая игра:
  раскладка, сложность, сброс -> заставка мира -> уровень
уровень пройден:
  последний в мире (+$40) -> LEVEL COMPLETE (+ пароль) -> бонус, если
    есть жетон -> заставка следующего мира -> уровень
  иначе -> следующий уровень сразу (после уровня 5 — сцена предупреждения)
  уровень 18 -> концовка -> титры -> снова с SEGA
гибель:
  экран гибели -> жизни есть: тот же уровень с точки возврата
               -> нет, есть продолжения: CONTINUE? вправо -> уровень
                  с начала; влево -> GAME OVER
               -> нет и продолжений: GAME OVER
  GAME OVER -> снова с SEGA
```

Музыку уровня (`+$3C` записи) включают при входе в игру, после гибели и
после мира: между уровнями одного мира она не прерывается. Заставка мира
идёт уже под музыку уровня.

## 2. Заставки при включении

| экран | что на экране | держится | пропуск |
|---|---|---|---|
| SEGA | логотип (`$1F70BC` + карта `$1F7058`, палитра `$1F74BE`); через 60 кадров блеск: каждые 2 кадра 22 цвета с индекса 2 сдвигаются по таблице `$1F7480` | 60 + 180 | нет |
| Disney Interactive | логотип (`$1F7772` + `$1F753E`) | 180 | Start |
| presents | «presents DONALD Starring In» (`$1F0D58`), плоскость B опущена на 20 точек (вертикаль −20) | 180 | Start |
| титульный | логотип MAUI MALLARD на A поверх задника с лучами, лозами и изгородью на B; звук 0 | 600 (PAL 500) | Start |

Логотипы SEGA и Disney — чужие товарные знаки; в ремейке их место займут
свои.

**Титульный экран** (`$28FB02`) живёт тремя приёмами:

* логотип въезжает: вертикальная прокрутка плоскости A от 32 до 224 по
  точке за кадр (192 кадра), потом появляется спрайт в (144, 196),
  скрипт `$1D6E92`;
* нижние 48 строк — «вода»: построчная волна по таблице `$1EA892`, шаг
  раз в 3 кадра (`$28FD6A`);
* с 190-й строки прерывание строки меняет вертикаль построчно —
  отражение (`$28FD04`).

Не нажал Start за 600 кадров — всё равно главное меню.

## 3. Меню и пароль

**Главное меню** (`$2908FA`, описатель `$1FD440`): START, OPTIONS,
PASSWORD по центру, строки 9, 12, 15. Срок — **600 кадров** (PAL 500) с
момента входа, **нажатия его не сбрасывают**; вышел — демо.

**Управление во всех меню** (`$297448`):

| что | кнопки |
|---|---|
| выбрать пункт | вверх-вниз, по кругу |
| пункт-процедура (START, EXIT) | только **Start** |
| выбор из списка | влево или A — назад, вправо или B — вперёд, по кругу; **Start** выходит из меню |
| SOUND TEST | влево-вправо — номер, **C** — сыграть |

**Настройки** (`$1FD4AA`, срока нет):

| пункт | значения | хранится |
|---|---|---|
| DIFFICULTY | NORMAL, HARD, PRACTICE | `$FFFD7C` |
| SOUND TEST | номер звука 0-168 по кругу: 169 — операнд `$A9` пункта; C — остановить всё и сыграть ([sounds.md](sounds.md)) | `$FFFD85` |
| CONTROLS | шесть раскладок: `A-POWERUP / B-SHOOT / C-JUMP` (по умолчанию) и ещё пять | `$FFFD7B` |
| EXIT | | |

Что даёт сложность — [behavior.md](behavior.md), 1.1; как раскладка
переставляет кнопки — [engine.md](engine.md).

**Пароль** (`$29098C`): надпись PASSWORD, шесть букв A-Z. При включении
буфер — `AAAAAA`, дальше остаётся последнее введённое.

| кнопки | что |
|---|---|
| влево-вправо | курсор по кругу |
| вверх или A | буква назад (A -> Z) |
| вниз или B | буква вперёд (Z -> A) |
| Start | проверить: верный — звук `$31`, 60 кадров и игра с уровня пароля; неверный — главное меню |

Пароли: `ININJA` -> 3, `ILVMUD` -> 7, `ITSHOT` -> 10, `GETHIM` -> 12,
`YOHOHO` -> 14, `UNDEAD` -> 16, `GDLUCK` -> 18. `IMCARY`, затем `MAUIMM`
открывают пункт DEBUG ([engine.md](engine.md)).

## 4. Демо

Три записи по кругу (`$1FD7DC`, счётчик `$FF21F4`): уровень 0 — 2995
кадров, уровень 3 — 4903, уровень 7 — 3503. Запись — пары байт «кнопки
(активный ноль), сколько кадров», ноль — конец (`$2A5694`). Перед демо —
обычная заставка мира. Поток кончился — снова с логотипа SEGA; **Start** —
сразу титульный экран и меню.

## 5. Заставка мира и сюжет

Идёт в начале каждого мира: новая игра, после LEVEL COMPLETE, вход в
бонус (`$28E970`). Силуэт острова `$1F6850`, задник, палитра `$1F6ED8`.

1. Страницы сюжета мира: строки по центру экрана, блок — вокруг
   y = 192; страница держится свой срок, между страницами 10 кадров.
2. Кончились страницы — буквы названия мира падают с высоты 256 над
   своим местом по 8 точек за кадр и после посадки держатся
   **180 кадров**.
3. Конец. **Start** пропускает заставку в любой момент.

| мир | названия уровней | страниц | по сколько кадров | о чём |
|---|---|---|---|---|
| 0-2 | THE MOJO MANSION | 4 | 150 | идол SHABUHM SHABUHM пропал |
| 3-6 | NINJA TRAINING GROUNDS | 4 | 180 | «пора сменить костюм» |
| 7-9 | MUDDRAKE MAYHEM | 5 | 180 | крошечные воины хотят чучело Мауи |
| 10-11 | THE SACRIFICE OF MAUI | 5 | 180 | союз муддрейков, «высшая честь» |
| 12-13 | THE TEST OF DUCKHOOD | 6 | 180 | «Мауи, я был не прав…» |
| 14-15 | THE FLYING DUCKMAN | 8 | 90-150, первая через 180 | шаман Квакко мёртв, его останки на дне |
| 16-17 | THE REALM OF THE DEAD | 4 | 180 | дух Квакко неспокоен |
| 18 | MOJO STRONGHOLD | 7 | 180 | Мауи стал ниндзя, «последняя опасность» |
| 19-22 | BABALUAU BABY | — | — | только актёр |

Полные тексты — `story.worlds` в JSON. После заставки мира 18 идёт ещё
сцена оплота (`$28EABE`): своя картинка (`$284BD6`, `$283D14`), фон
построчно, как на уровне 18, актёры `$1EA5A2`; конец — когда разойдутся
актёры или по Start.

**Сцена после уровня 5** (`$28E9C6`, ставит процедура уровня 5 через
`$FF1360`): чёрный фон, дух идола, первая страница через 180 кадров:
«MAUI!» / «THE LEGENDS FORETELL ONLY A GREAT WARRIOR WILL SAVE US...» /
«NOT YOU!» / «DON'T GET INVOLVED!» / «YOU'LL JUST RUIN EVERYTHING LIKE
ALWAYS!» / «THIS IS YOUR ONLY WARNING!!!». (Этим закрыта дыра из
[levels.md](levels.md), раздел 5.)

## 6. Итоги

**LEVEL COMPLETE** (`$290494`) — после последнего уровня мира: музыка
`$53`, силуэт острова `$1F6548` и задник, палитра `$1F6F58`. Через 160
кадров буквы надписи начинают падать с y = −32 по 6 точек за кадр,
каждая следующая на кадр позже, до y = 72 (`$2900DE`). Если мешков денег за мир **не меньше 12**, внизу
`PASSWORD:` с (88, 184) и шесть букв пароля следующего мира с (112, 200)
([levels.md](levels.md), 2.5). Держится **550 кадров**, пропуск — Start.

**Итог бонуса** (`$28EBFA`) — после бонусной игры, на фоне заставки мира:

* бонус проигран (кончился с «−1») или стопка пуста — надпись
  **NO BONUS**, 210 кадров;
* иначе все призы стопки применяются сразу (`$29FEC2`): 0 — жизнь (до 9),
  1 — продолжение, 2 — потолок здоровья +50 и здоровье +50 (сложение
  десятичное: `moveq #80` — это `$50`), 3 — серия
  ниндзя +1. На экране призы стоят в ряд по центру, Мауи вбегает слева и
  лопает каждый (звук 1), потом надпись **COWABUNGA**.

Пропуск — Start.

## 7. Гибель, продолжение, конец игры

**Экран гибели** (`$2903A8`): чёрный, два актёра (`$1EA992`: Мауи
падает, всплеск), палитра `$1FB158`, **110 кадров**, пропуск — Start.
Дальше жизни −1: если остались — тот же уровень с точки возврата.

**Продолжение** (`$29066A`) — если жизней нет, а продолжений больше
нуля: музыка `$56`, силуэт и задник. Через **160 кадров** сверху
падают стрелки «no» влево (x = 100) и «yes» вправо (x = 220) до y = 112, а
через 10 кадров — надпись **CONTINUE** (до y = 56). Ответа ждут **без
срока**: **вправо — да, влево — нет**; стрелки разъезжаются по 8 точек за
кадр, надпись улетает вверх, через 60 кадров экран гаснет. Да — продолжения −1, жизни и
здоровье как на старте, точка возврата стёрта: уровень с начала. Нет —
конец игры.

**GAME OVER** (`$28ED64`): музыка `$97`, силуэт и задник, актёры
`$1EA5D8`; когда актёр дошёл до места, падает надпись **GAME OVER**, и
через **240 кадров** — снова заставки с SEGA. Пропуск — Start.

## 8. Концовка и титры

После уровня 18 (`$28DCEC`), музыка `$99`:

1. Ночной берег: пальмы и небо (`$1F2CEC`, `$1F3270`), анимация тайлов
   `$1E9672`, актёры. Камера съезжает вниз по 4 точки за кадр, и идёт
   прощальная речь островитян, которые считают Мауи погибшим, —
   16 страниц (`$1E92F0`, 120-180 кадров каждая): «MAUI, YOU DID IT…» …
   «THE STARS.» Следом девять страниц титров в сцене (`$1E9352`, по 180
   кадров): программист, продюсеры, художники, уровни, музыка.
2. Свиток титров 40 × 404 клетки (`$1F3B4A`) поверх задника титульного
   экрана: вверх на точку раз в 2 кадра до конца свитка, та же «вода»,
   что на титульном. Держится до **6180 кадров** (103 секунды),
   пропуск — Start. Если концовку пропустили Start, свиток не
   показывают вовсе: он идёт, только когда речь дошла до конца
   (`$FF000E`).
3. Снова заставки с SEGA.

## 9. Пауза

**Start** на уровне включает и выключает паузу (`$298C50`); во время
землетрясения уровня 3 — нельзя (`$FF217C`). В паузе объекты и
анимация стоят, спрайты рисуются, звук код паузы не трогает; лицо в HUD
перебирает
три кадра (`$1EF65E + $240`) по 12 кадров. Надписи «PAUSE» нет.

При открытом DEBUG Start с кнопкой — читы: с C — запасы жуков 1 и 3 по
999, с A — гибель, с B — уровень пройден и жетон бонуса.

## 10. HUD

Пять спрайтов, у каждого свой кадр в ОЗУ (`$299028` по таблице
`$298FBA`); перерисовывается спрайт, только когда меняется его значение
(`$299306`).

| где (x, y) | размер | что | глифы |
|---|---|---|---|
| (28, 30) | 16 × 16 | **жизни** — одна большая цифра, не больше 9 | `$1ECC9E` |
| (41, 22) | 24 × 24 | **лицо**: утка или ниндзя | `$1EF65E` |
| (39, 48) | 24 × 8 | **здоровье** — три малые цифры, ведущие нули пустые, не больше 999 | `$1EE99E` |
| (284, 24) | 32 × 32 | утка и уменьшенный: **значки жуков** выбранного набора, до трёх; ниндзя: **инь-ян**, 16 кадров, смена раз в 4 кадра | `$1EF3DE`, `$1EEBDE` |
| (284, 56) | 32 × 16 | утка: **запас** под каждым значком, две цифры, не больше 99; ниндзя: **топливо**, три цифры, не больше 999 | `$1EE99E` |

Лицо: у ниндзя — ниндзя; у утки без топлива — утка; у утки с топливом
лицо раз в **90 кадров** меняется утка/ниндзя — подсказка, что можно
превратиться. Значки по наборам (`$2990FC`): 0 — жук 0 без числа; 1, 2,
4 — один значок; 3, 5, 6 — два; 7 — три; «нет оружия» — пустой значок.

Координаты — точки объектов-спрайтов в экранных точках; где у их кадров
начало, в выгрузку не сведено (раздел 12).

## 11. Находки и поправки

* **Мёртвое:** экран `$29080E` (чёрный с актёрами `$1EA9AC`, 180 кадров) —
  ни одной ссылки; надпись **THANKS FOR PLAYING** (`$1FC632`) — ни одной
  ссылки; **шкала топлива** из `$1EACF0` (процедура `$296A20`) — никто не
  зовёт. В [player.md](player.md) сказано, что шкала рисует топливо; на
  экране топливо — три цифры в правой панели ниндзя.
* Главное меню уходит в демо через 600 кадров, даже если игрок жмёт
  кнопки; у экрана продолжения срока нет вовсе.
* Сцена `$28E9C6` после уровня 5 — предупреждение духа идола (раздел 5).
